# 屋外ルート（建物の外・建物から建物への移動）

2026-11-18 決定。屋内のルート案内（`src/core/VenueRouter.js`・`src/ui/RouteView.js`）を、建物の外の周辺地図までつなぐ。

## 1. 決まっていること

| 項目 | 決定 |
|---|---|
| 地図の作り方 | OpenStreetMap（OSM）のデータを前もって取り、静的な SVG と歩く道の網にする（当日は通信しない） |
| 外の扱い | 周辺地図を 1 枚の「階」として扱う（`outdoor: true`） |
| 距離 | メートルで数える。階ごとに `metersPerPx` を持つ |
| 徒歩の時間 | **建物の外を通るときだけ**「徒歩約 N 分」を出す。分速 80m、切り上げ、最短 1 分。重なりの警告には使わない |
| 屋内 ⇔ 屋外の見せ方 | **ズームアウト／ズームイン**。屋内図が周辺地図の建物の形へ縮みながら回り（向きが分かる）、外の地図に替わる。動きを減らす設定では即座に切り替える |
| 屋内 ⇔ 屋内 | 今のまま（上下のスライド＋フェード） |
| 階のつなぎ方 | `link`（つなぎ先のキー）が同じ点どうしを、隣り合う階でつなぐ。表示名（`name`）は階ごとに変えてよい |
| サンプルの別館 | 名前は **別館A・別館B**。住所の別名や、実在のお店が分かるメモは置かない |
| サンプルの表示 | 枠で目立たせず、地図の右下に灰色の小さな文字で「この地図はサンプルです」とだけ書く。**実在の施設名・通りの名前は、画面にもリポジトリのファイルにも出さない**（パス・ID も一般名。OSM の保存データからも名前を除く） |
| サンプルの周辺地図 | **通りの名前を描かない**（サンプルの間は場所を特定させない）。生成ツールの `street_labels=False` |
| 別館の入口 | 「外壁のうち、いちばん道に近い点」の推定。直すときは `tools/sample-venue/doors.json` に緯度経度を書く（編集ツールで点を動かすと緯度経度が出る）。作り直しても残る |
| サンプル会場の向き | 正面入口は **東向き**（大通り側）。屋内図の下が東になる |
| 出典・ライセンス | 地図に「地図データ © OpenStreetMap contributors」。取得したデータと、それをもとにした座標は ODbL（`public/venues/sample-hall/LICENSE-OSM.md`） |
| 取得先 | Overpass API を先に、だめなら OSM API（`api.openstreetmap.org`）。取得したデータはファイルに残し、通信なしで作り直せるようにする |

今回やらないこと：徒歩の時間を重なりの警告に使う／主催スプシの変更／ほかの会場の地図。

## 2. venue_map.json の形（足すもの）

今の地図はそのまま動く（足すものはすべて省略できる）。

```jsonc
{
  "floors": [
    { "id": "1F", "label": "1階", "image": "./1f.svg", "width": 1720, "height": 1130,
      "metersPerPx": 0.032,
      // この階が周辺地図のどこにあるか：屋内図の outline（建物の外形の四角）を、
      // 周辺地図の center を中心に size の大きさで、rotation 度（時計回り）回して置く
      "footprint": { "floor": "OUT", "outline": [35, 107, 1647, 980], "center": [860, 560], "size": [180, 120], "rotation": -76 } },
    { "id": "OUT", "label": "屋外", "outdoor": true, "image": "./outdoor.svg", "width": 1720, "height": 1240, "metersPerPx": 0.09 }
  ],
  "nodes": [
    { "id": "1f-ent", "floor": "1F", "x": 990, "y": 905, "kind": "entrance", "name": "正面入口", "link": "main-entrance" },
    { "id": "out-ent", "floor": "OUT", "x": 912, "y": 600, "kind": "entrance", "name": "本館 正面入口", "link": "main-entrance" },
    { "id": "out-a", "floor": "OUT", "x": 400, "y": 380, "room": "別館A", "note": "西側の通り沿い" }
  ]
}
```

- `focus`（屋外の階）：「全体」表示で見せる範囲 `[x0, y0, x1, y1]`。広い周辺地図でも会場のあたりを大きく見せる
- `metersPerPx`：**すべての階**にあれば、道の重みをメートルで数える（無い階が 1 つでもあれば、今までどおり px）
- 階をまたぐ既定の重み（メートル）：階段 15・エレベーター 30・出入口 5（px の地図では今までどおり 400）
- `kind: "entrance"`：建物の出入口。ドアの印で案内する
- `link`：同じ値の点を、`floors` の並びで隣り合う階どうしでつなぐ（明示した `edges` があればそちらが優先）
- `note`：到着した部屋の目印。到着の案内に出す

- 片方が出入口で、もう片方がエレベーター・階段の階またぎ（例：1 階の図が無く、3 階のエレベーターと屋外の「1階 出入口」を edges でつなぐ）は「出入口」として扱う。
  案内は「エレベーターで降り、1階 出入口から外へ」。距離は edges に書いた重み（メートル）で数える

## 3. ルート計算（`VenueRouter.route`）の戻り値に足すもの

- `note`：到着の部屋の目印（無ければ空）
- `exitVia.through` / `enterVia.through`：種類の違う点どうしの階またぎで、もう一方の名前
- `walk`：外を通るときだけ `{ meters, outdoorMeters, minutes }`。外を通らなければ `null`
- `exitVia` / `enterVia` の `name` は、それぞれの側の点の名前（片方しか無ければその名前）

## 4. 画面

- **予定一覧の移動の帯**：外を通るときは「徒歩約 N 分」の印を付け、「（正面入口から外へ）」のように出口を書く。周辺地図の上にある部屋には階の名前を付けない
- **ルート案内**
  - 見出しに「徒歩約 N 分」。外を通るときは「会場間のルート」と書く
  - 出入口はドアの印。「正面入口から外へ」「別館A 入口から1階へ」
  - 到着の案内に `note` を添える
  - 屋内 ⇔ 屋外：上のズームアウト／ズームイン（約 1.1 秒）。終わってから外のルートの線を描く

## 5. 道具

- `tools/outdoor-map/osm_outdoor.py`（README あり）：会場（OSM の建物）と余白から範囲を決め、OSM を取得・保存し、歩ける道の網を作り、出入口をいちばん近い道につなぎ、SVG（道・建物・通りの名前・方位・縮尺・出典・右下の小さな断り書き）を描く
- `tools/sample-venue/build_sample_hall.py`：上を呼び、屋内 3 階＋屋外 1 枚の venue_map.json を作る
- `tools/venue-editor.html`：出入口の種類、`link`・`note` の入力。書き出しで `link` を優先してつなぐ

## 6. 完了の条件

1. `node --test tests/venue-router.test.js`：メートル・link・出入口・メモ・徒歩分・今の地図との互換が通る
2. サンプルの公演の部屋名がすべて地図にある（`unknownRooms` が空）
3. `npm run build` が通る
4. `/sample/` で、1日目に本館 3F 第7会議室の公演（10:30）と別館B の公演（11:45）を選ぶと、移動の帯に「徒歩約 N 分」が出る
5. 「ルートを見る」で 3F → 南階段 → 1F → 正面入口 →（ズームアウト）→ 周辺地図 → 別館B に到着、目印が出る。逆向きはズームイン
6. スクリーンショットと録画で 4・5 を確かめる

## 7. サンプル

| URL | 中身 | 生成 |
|---|---|---|
| `/sample/`（`?mock=sample`） | 3 階建ての会館＋同じ街区の別館A・別館B（徒歩約1〜3分） | `tools/sample-venue/build_sample_hall.py` |
| `/sample2/`（`?mock=sample2`） | ビルの 3〜5 階＋駅前の広場まで（約700m・徒歩約10分）。1 階の図は無く、エレベーターで降りて 1 階の出入口から外へ | `tools/sample-venue/build_sample_hall2.py` |

- どちらも実在の施設名・通りの名前は出さない（部屋・建物は一般名）。OSM の保存データからも名前を除く
- 広い範囲の周辺地図では、地下街・地下道・建物の中の通路（tunnel・layer が負・indoor・corridor）を道の網に使わない（地上の地図に重ねると分かりにくいため）
- 屋内 ⇔ 屋外のズームは、建物（footprint の中心）の画面上の位置をなめらかに動かす。建物が「全体」表示の端にあっても、ズームの途中で画面から消えない
- 方位・縮尺・出典・断り書きは、「全体」表示で見える範囲のうち会場から遠い隅に置く
